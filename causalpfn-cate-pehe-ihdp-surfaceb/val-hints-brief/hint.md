The generator uses one sparse coefficient vector shared by both arms, drawn from a small discrete grid, and the treated cohort is the same fixed set of rows in every dataset with its average effect pinned to an exact constant. Impose that constant as a hard constraint, then search the grid by profiled coordinate descent with pair and triple escape moves, using a smooth likelihood to search and the exact one only to re-rank near-optimal candidates. Aggregate candidates with a weighted geometric median, since the metric averages per-dataset RMSE.
